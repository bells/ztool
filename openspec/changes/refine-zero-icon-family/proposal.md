## Why

Zero's current icon family is technically unified but its most visible metaphors are still weak: the circular Zero mark does not express the intended duck-egg identity, the Awake steam consumes scarce status-bar space, and the Launch terminal prompt reads as a command line rather than launching. Refining these three marks now makes the application, native menu bar, and React surfaces more recognizable without changing their behavior.

## What Changes

- Replace the circular/textual Zero foreground with one solid duck-egg silhouette that is narrower above and fuller below, cut by a precise negative 45-degree slash and reused in the main-window and About marks, application bundle icon, and transparent status icon.
- Replace the Zero Awake steaming-cup geometry with a larger steam-free cup and saucer while preserving a bounded active-state treatment and stable status-item bounds.
- Replace the Zero Launch `>_` terminal prompt with a sparse, forward/upward rocket glyph that remains recognizable at 16px through 24px.
- Regenerate native tray PNGs, the application bundle icon family, React icon sources, and the icon contact sheet from the canonical SVG masters.
- Preserve monochrome transparent native artwork and macOS Template Image behavior so the complete grouped status item follows system light/dark appearance automatically.
- Extend automated geometry/source checks and require real macOS menu-bar review for the refreshed normal and Awake active states.
- Leave Zero Snap, Zero Paper, the generic extension glyph, status-item order, actions, hit targets, plugin contracts, IPC, and window behavior unchanged.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `zero-icon-system`: Refines the canonical Zero, Zero Awake, and Zero Launch identities, their small-size acceptance criteria, derived assets, and native Template Image verification. This capability is currently established by the active `design-zero-icon-system` change and must be synchronized before this follow-up delta is archived.

## Impact

- Canonical SVG sources and icon documentation under `src/assets/icons/` and `docs/icon-system.md`.
- React main-window and About surfaces that currently draw independent text `Z` marks in `src/App.tsx`, `src/core/preferences/AboutPanel.tsx`, and `src/App.css`.
- Deterministic validation, contact-sheet, tray-generation, and application-icon generation in `scripts/icon-system.mjs` plus focused source-contract tests.
- Generated native assets under `src-tauri/icons/tray/` and the Tauri bundle icon set under `src-tauri/icons/`.
- Existing Rust asset loading and grouped macOS status-item composition remain structurally unchanged, but their embedded generated bytes change.
- Existing typed React status-icon mappings remain compatible and continue to consume the same filenames through CSS masks.
- No new runtime dependency, network access, IPC shape, serialized icon identifier, or plugin behavior is introduced.

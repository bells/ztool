# Agent Instructions

This repository contains a Tauri 2 desktop app named Zero.

## Project Shape

- Frontend: React 19 + TypeScript + Vite under `src/`.
- Native shell: Tauri 2 + Rust under `src-tauri/`.
- App concept: tray-first utility collection. Each user-facing tool should behave like a plugin.
- Host core lives under `src/core/pluginHost` and `src/core/preferences`.
- Bundled plugins are isolated under `src/plugins/{caffeine,bingWallpaper,quickLauncher,screenshot}` and register through `src/appShell/bundledPluginModules.ts`.

## Development Rules

- Prefer small, plugin-scoped changes over large app-wide rewrites.
- Keep each plugin's UI and state bridge close to that plugin.
- Add Rust commands under `src-tauri/src/commands/`.
- Add native business logic under `src-tauri/src/services/`.
- Register new Tauri commands in `src-tauri/src/lib.rs`.
- Update `src-tauri/capabilities/default.json` when a new Tauri plugin or permission is needed.
- Do not commit generated output such as `dist/`, `node_modules/`, or `src-tauri/target/`.

## UI Guidance

- The app is a compact tray control center, not a marketing site.
- Preserve the three-part shell:
  1. Tool list
  2. Current tool display
  3. System actions and preferences
- Keep controls dense, readable, and stable at the configured tray window size.
- Use familiar compact controls for toggles, tool actions, and system actions.

## Verification

Run these checks before considering a change complete:

```bash
pnpm test
pnpm build
cd src-tauri
cargo fmt --check
cargo check
cargo test
```

For UI changes, also run:

```bash
pnpm tauri dev
```

Then inspect the tray window manually.
